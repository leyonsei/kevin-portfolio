# Luong (Kevin) Tsai — Portfolio Website

A responsive, self-contained static portfolio site based on the provided homepage reference image. No framework, build step, paid service, or external JavaScript library required.

## View the website

Open `index.html` in any modern browser. The navigation, project jump link, LinkedIn link, email link, and Resume PDF link work out of the box.

## Publish it for free

- **GitHub Pages:** create a new repository, upload the contents of this folder to the repository's root, then enable Pages in **Settings → Pages → Deploy from a branch → main / root**.
- **Netlify:** drag the **unzipped website folder** into Netlify's site deploy area.

## Customize

- Edit `index.html` for biography, project details, dates, and external links.
- Edit `assets/styles.css` for color, fonts, spacing, and layout.
- Replace files in `assets/images/` with your real project images, or edit the corresponding `<img src="...">` paths in `index.html` if using JPG/PNG/WEBP.
- Replace `assets/Luong_Tsai_Resume.pdf` with your newest resume, keeping the filename to avoid changing links.

The LinkedIn link was obtained from the link embedded in your uploaded resume. The uploaded PDF resume is included. The project illustrations are original schematic placeholders, not photos of your actual prototypes.
